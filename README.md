# Scale-SETI

**Current review baseline assembled.**

Repository: [TimBoccaleri/Scale-SETI](https://github.com/TimBoccaleri/Scale-SETI).

Scale-SETI explores physical scale as a possible search dimension for technological intelligence. It is a speculative research concept, not evidence for other domains or civilizations. Phase 1 validates the methodology using a conventional microscopic communication channel; supplied datasets are synthetic.

## Work locally

Clone the repository into a folder of your choice and open this README or the folder in your editor. Edit the source format you choose and regenerate its reading copy when the content changes; record which format is authoritative for each future change so Markdown and Word do not drift silently.

Alternatively, download the repository ZIP from GitHub and extract it into a folder of your choice. Avoid extracting over an existing working copy with newer edits.

The original downloads are retained locally under `local-originals/` and excluded from Git and the clean distribution ZIP. They are backup/provenance inputs, not another current document tree. No superseded revisions were supplied. This working folder is connected to the GitHub repository linked above.

## Scope and review

The concept paper, engineering design and future experimental results are separate products. The roadmap controls scope; an up-scale spacecraft architecture remains future work. Reviewers should begin with the guide and concept paper. Engineering material is supporting detail; the feedback form is optional, and email comments are equally useful.
