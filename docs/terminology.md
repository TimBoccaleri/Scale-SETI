# Terminology

Starter glossary aligned with the supplied Candidate 1.0 and v0.3 baseline; the documents remain authoritative.

| Term | Meaning in this workspace |
| --- | --- |
| Scale-SETI | A proposed search framework considering physical scale as a search dimension; not an established communication mechanism. |
| Same-Scale SETI | Searches across spatial distance within our observable physical regime. |
| Down-Scale SETI | The conceptual search toward smaller physical-scale domains. |
| Up-Scale SETI | The conceptual search for interaction with a larger physical-scale domain. |
| Shared interface | A hypothesized interaction boundary; its existence and ability to convey information must not be assumed. |
| Wall analogy | An explanatory analogy for indirect interaction through a shared interface, not physical evidence. |
| Concept Paper Candidate 1.0 | The current scientific-argument document; candidate status does not imply external approval. |
| Phase 1 | Known-physics methodology validation using a conventional microscopic communication channel. |
| Design Package v0.3 | The current engineering baseline, separate from future fabrication/build releases. |
| Synthetic data | Simulated inputs or outputs for software dry runs; not hardware observations or evidence for the hypothesis. |
| Control | An experimental condition used to test conventional explanations and pipeline behavior. |
| External technical review | Criticism of framing, novelty, controls, statistics and reproducibility; not endorsement. |
| Acceptance | Documented satisfaction of specified criteria, requiring the appropriate evidence. |
